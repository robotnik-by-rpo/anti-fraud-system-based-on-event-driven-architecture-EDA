# Разработка отказоустойчивой антифрод-системы для финансовых транзакций на основе событийно-ориентированной архитектуры (EDA)

# Стек:
 * Golang (основа)
 * Python (основа)
 * Docker (основа)
 * gRPC (основа)
 * Redis (основа)
 * PostgreSQL (основа)
 * bash (основа)
 * Kafka (основа)
 * Docker-compose (для локальной разработки и тестов) (основа)
 * Kubernetis (k8s) (опционально)
 * Grafana (опционально)
 * Prometheus (опционально)
 * Golang-migration (опционально)
 * CI/CD (опционально)

# Архитектура проекта:
 * deploy - конфигурации k8s
 * docs - документация
 * ml - обучение нейросети
 * scripts - вспомогательные скрипты для проекта
 * services - микросервисы
 * shared - общие библиотеки/контракты
