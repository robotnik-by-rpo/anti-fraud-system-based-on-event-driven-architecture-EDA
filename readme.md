# Отказоустойчивая антифрод-система для финансовых транзакций на основе событийно-ориентированной архитектуры (EDA)
Проект для курсовой работы. Проект представляет из себя антифрод-систему для выявления мошеннических транзакции и последующей блокировкой этих транзакций. Проект написан на "современном" продакш стеке технологий.

# Стек:
 * Golang (основа)
 * Python (основа)
 * Docker (основа)
 * gRPC (основа)
 * Redis (основа)
 * PostgreSQL (основа)
 * bash (основа)
 * Kafka (основа)
 * Docker-compose (для локальной разработки и тестов) (основа)
 * Golang-migration (основа)
 * Swagger (основа)
 * Kubernetis (k8s) (опционально)
 * Grafana (опционально)
 * Prometheus (опционально)
 * CI/CD (опционально)

# Архитектура проекта:
 * deploy - конфигурации k8s
 * docs - документация
 * ml - обучение нейросети
 * scripts - вспомогательные скрипты для проекта
 * services - микросервисы
 * shared - общие библиотеки/контракты
