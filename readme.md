# Отказоустойчивая антифрод-система для финансовых транзакций на основе событийно-ориентированной архитектуры (EDA)
Проект для курсовой работы. Проект представляет из себя антифрод-систему для выявления мошеннических транзакции и последующей блокировкой этих транзакций. Проект написан на современном коммерческом стеке технологий.

# Стек:
 * Golang (основа)
 * Python (основа)
 * Docker (основа)
 * gRPC (основа)
 * Redis (основа)
 * PostgreSQL (основа)
 * bash (основа)
 * Kafka (основа)
 * Docker-compose (для локальной разработки и тестов) (основа)
 * Golang-migration (основа)
 * Swagger (основа)
 * Kubernetis (k8s) (опционально)
 * Grafana (опционально)
 * Prometheus (опционально)
 * CI/CD (опционально)

# Архитектура проекта:
 * deploy - конфигурации k8s
 * docs - документация
 * ml - обучение нейросети
 * scripts - вспомогательные скрипты для проекта
 * services - микросервисы
 * shared - общие библиотеки/контракты
 * tests - общие тесты проекта

# Таргеты
|Таргет|Описание|
|------|--------|
|dc-up|Запуск системы через Docker compose|
|dc-wait-up|Запуск системы через Docker compose со "здоровыми" сервисами|
|venv|Инициализация вирутального Python окружения|
|ml-lib-cpu|Скачивание ML библиотек для работы на CPU|
|ml-lib-cuda|Скачивание ML библиотек для работы на GPU|
|ml-util-mamba|Скачивание библиотек для работы модели архитектуры Mamba|
|ml-model-cpu|Скачивание модели Mamba для обучения на CPU|
|ml-model-gpu|Скачивание модели Mamba для обучения на GPU|
|ml-train|Запуск обучения модели Mamba|
|ml-evaluate|Запуск модели Mamba на валидационном датасете|
|update-time|Замена времени в датасете через скрипт|
